# bp_diary_bot — дневник артериального давления

Telegram-бот для ведения дневника измерений давления. Пользователь присылает строку вида
`120 80` (САД ДАД) или `120 80 75` (САД ДАД пульс), бот валидирует, спрашивает самочувствие,
сохраняет в SQLite, показывает статистику, историю и график, умеет чистить старые данные и
напоминать о замере по расписанию.

> ⚠️ Бот — журнал измерений, а не медицинское устройство. Не ставит диагнозов, не трактует
> значения, не выдаёт «норм». Пороги валидации — только защита от опечаток.

## Структура

```
bot.py              точка входа: Application, хендлеры, post_init
config.py            конфигурация (pydantic-settings, .env)
keyboards.py          постоянная reply-клавиатура + inline-клавиатуры
db/                    модели и асинхронный доступ к SQLite (SQLAlchemy 2.0 + aiosqlite)
services/               парсинг, лимиты, статистика, график, напоминания, стикеры
handlers/                команды и диалоги бота
stickers.json             наборы стикеров-реакций на замер
bp_diary.db                база данных (создаётся автоматически)
docs/bp_diary_bot_tz.md    полное ТЗ
```

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и вписать BOT_TOKEN
```

## Запуск

```bash
.venv/bin/python bot.py
```

## Запуск через PM2

```bash
# Установить PM2 (один раз)
npm install -g pm2

# Запустить бота
pm2 start ecosystem.config.js

# Автозапуск при перезагрузке сервера (один раз)
pm2 startup
pm2 save
```

## Деплой на сервер

```bash
./gp.sh   # git pull + pip install + pm2 reload --update-env + pm2 save
```

## Управление ботом

Основной способ — постоянная клавиатура внизу экрана (появляется после `/start`):

| Кнопка | Действие |
|---|---|
| ➕ Добавить замер | подсказка по формату ввода |
| 📊 Статистика | статистика за период |
| 📋 История | последние записи таблицей |
| 📈 График | график динамики |
| 🗒 Всё сразу | статистика и история одним ответом |
| 🗑 Очистить | очистка старых данных (inline-меню) |
| ⚙️ Напоминания | вкл/выкл, добавить/убрать время (inline-меню), до 5 времён |
| ❓ Помощь | формат ввода и список кнопок |

Запись замера — не кнопкой, а строкой вида `120 80` или `120 80 75` (САД ДАД [пульс]),
присланной в любой момент; дальше бот сам спросит самочувствие инлайн-кнопками.

Команды `/start`, `/help`, `/cancel` работают как обычно; остальные (`/stats`, `/history` и т.д.)
оставлены рабочими для совместимости, но не рекламируются — используйте кнопки.

## Напоминания

Времён может быть несколько (по умолчанию до 5) — например 09:00 и 22:00. В «⚙️ Напоминания» →
«➕ Добавить время» можно ввести сразу несколько за раз: `09:00 22:00` или `9:00 и 22:00`.
Лимит меняется через `MAX_REMINDERS_PER_USER`.

## Стикеры

После выбора самочувствия бот отвечает случайным стикером из `stickers.json`. Ключ набора
выбирается по цепочке **категория давления → тон → `any`**, первый непустой набор выигрывает;
если ничего не подошло — стикер просто не отправляется.

| Ключ | Когда | Границы (ESC/ESH 2023, решает худший показатель) |
|---|---|---|
| `hypotension` | пониженное | САД < 90 или ДАД < 60 |
| `optimal` | оптимальное | до 119/79 |
| `normal` | нормальное | 120–129 / 80–84 |
| `high_normal` | пограничное | 130–139 / 85–89 |
| `grade1` | повышенное | 140–159 / 90–99 |
| `grade2` | повышенное | 160–179 / 100–109 |
| `grade3` | сильно повышенное | от 180 или от 110 |

Тона `positive` / `neutral` / `negative` — запасные наборы: можно заполнить только их и получить
грубое деление, а категории оставить пустыми. Плохое самочувствие («Плохо», «Так себе») сдвигает
тон на ступень вниз; хорошее самочувствие при плохом давлении весёлый стикер не вернёт.

`file_id` стикера можно узнать, переслав его боту `@RawDataBot` или `@idstickerbot`. Файл
перечитывается на лету — после правки перезапуск бота не нужен. Отключается `STICKERS_ENABLED=false`.
